WrangleBot

Corralling rogue agents.

A local supervisor daemon for autonomous coding agents. Breaks loops, fences diffs, ships clean sessions.

wranglebot — supervised session 
$ wranglebot run claude-code --workdir . --scope src/auth --scope tests/auth

[wranglebot] out-of-scope edit blocked · src/billing/invoice.ts
[wranglebot] session emitted · session.curt (1,842 → 210 lines)
01

LOOP BREAKER

Deterministic kill-switch. Fingerprints repeated tool calls, watches diff-delta across turns, halts the thrash before your token budget dies.

02

AST GUARDRAILS

tree-sitter validation on every edit before it lands. Illegal syntax and out-of-scope files never touch the worktree.

03

.CURT SESSIONS

Every supervised run emits a lean, portable .curt session. Audit-ready. First-class citizen of the Curtis ecosystem.
